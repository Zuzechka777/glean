# Зюзян: интеграция с reels-inbox

## Как добавить skill

Дай Зюзяну / Claude Code следующую инструкцию (как skill, хук на сообщение или системный промпт):

---

**Инструкция для Зюзяна:**

Если в сообщении пользователя есть ссылка вида `instagram.com/reel/` или `instagram.com/p/`:

1. Выполни в терминале:
   ```
   uv run --project ~/Projects/glean reels-inbox process-text "ТЕКСТ_СООБЩЕНИЯ" --json
   ```
   Замени `ТЕКСТ_СООБЩЕНИЯ` на полный текст входящего сообщения (ссылка будет найдена автоматически).

2. Разбери JSON-ответ и ответь пользователю в виде:
   - Тип карточки (путешествие / туториал / оффер / рецепт / AI-инструмент)
   - Заголовок
   - Краткое summary (1–2 предложения)
   - Стоимость обработки ($0.00X)
   - Если `degraded: true` — предупреди, что карточка неполная

3. Если `status: already_processed` — скажи «уже обработан» и укажи путь к заметке.

4. Если ошибка — сообщи об ошибке и предложи запустить вручную.

---

## Пример ответа Зюзяна

> 🗺️ **Тбилиси: 5 кафе с видом на Куру**
> Тип: travel · обработан
>
> Пять кафе в старом городе с видом на реку: Мтацминда, Фабрика, Дом Мелик-Азарянца. Адреса и Google Maps — в заметке.
>
> 💰 $0.0061 · заметка: Reels/2026-06-11-tbilisi-cafes.md

---

## Путь к исполняемому файлу

После установки на Mac через `setup.sh` команда `reels-inbox` доступна через:
```
uv run --project ~/Projects/glean reels-inbox
```

Или если добавить `.venv/bin` в PATH:
```
~/Projects/glean/.venv/bin/reels-inbox
```

---

## Ручной вызов без Зюзяна

```bash
cd ~/Projects/glean
uv run reels-inbox process "https://www.instagram.com/reel/XXXXX/" --json
```
